# Billy notifications and visitor acknowledgements

Use Dragon Lead Form 1.2.3. In WordPress → Plugins → Add New → Upload Plugin install dragon-lead-form-v4-1.2.3.zip, choose Replace current with uploaded, and activate if needed. Keep the theme and setup importer unchanged. Clear relevant page caches.

Settings → Dragon Contact Form: set notification email to billy@dragonoilfield.com. Leave visitor acknowledgements disabled until authenticated mail is configured. Enquiries are saved privately under Dragon Inquiries. Version 1.2.3 adds an Email notification attempts panel inside each enquiry. Accepted means accepted by WordPress/the transport, not confirmed inbox delivery.

Configure only one outgoing-mail plugin, for example WP Mail SMTP. The existing Google email DNS suggests Google Workspace is the intended provider. Prefer its supported Google/Gmail OAuth connection if available; the account owner must authorize it. Never send passwords, app passwords, OAuth client secrets or API keys in chat.

Alternatively, if the Google Workspace account permits app passwords, its owner can enable 2-Step Verification and create a dedicated WordPress app password at https://myaccount.google.com/apppasswords . With WP Mail SMTP → Other SMTP use host smtp.gmail.com, TLS, port 587, authentication enabled, username billy@dragonoilfield.com and that dedicated app password. Set From Email to billy@dragonoilfield.com, From Name to Dragon Oilfield Supply, and Force From Email. Never use the normal Google password or disable TLS verification. Google account/organization policy may prohibit app passwords; if unavailable, use OAuth or a verified transactional provider instead. Do not weaken account security settings to expose app passwords.

Keep existing Google MX records and the existing Google-authorizing SPF policy at GoDaddy. Do not add a second SPF record. Have the Google Workspace administrator confirm DKIM signing is enabled and review DMARC/authentication results. Use exact DNS records supplied by the actual sender service; verify existing keys before creating or changing records. Do not change nameservers or mail routing for this setup.

Send the SMTP plugin test to an address you control and confirm actual receipt. Then enable Send visitors an email acknowledgement in Settings → Dragon Contact Form and save. With your own separate email address submit a clearly labeled test enquiry. Billy should receive the full enquiry; the visitor gets a fixed We received your enquiry acknowledgement with Reply-To set to the configured business notification address. Submitted free text is deliberately not echoed in the receipt. Visitor acknowledgements are limited to one per email address per 15 minutes; normal enquiries still have a per-IP 45-second limit. Phone-only submissions have no recipient for a visitor email. When testing repeated acknowledgement delivery use another address you control or wait 15 minutes.

Check Dragon Inquiries for the saved content and each email attempt status; check both actual mailboxes and authentication headers (SPF/DKIM/DMARC). SMTP test success or wp_mail_accepted does not establish inbox delivery. No system can guarantee inbox placement. Local tests intercepted all mail; production sending and real inbox placement remain unverified.
