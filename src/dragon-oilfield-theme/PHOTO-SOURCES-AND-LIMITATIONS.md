# Photo sources in V4

The pattern references 11 approved old-site photo URLs, listed below. Tools → Dragon Site Setup must import all of them into the new Media Library before it creates Home. Successful partial imports are retained, and existing Home content is never overwritten. Image/cover blocks receive local URLs and attachment IDs.

Actual original downloads remain pending because the cloud network policy denied the source host. Local tests used clearly identified logo fixtures, not substitute product imagery. User-supplied inline photographs are reference material; downloadable originals were not available to the test runner. No Shopify screenshots or fabricated equipment photos are included.
